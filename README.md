# SmallForce Apps Template

Astro template for SmallForce generated apps. It supports SEO-first static sites, content sites with Astro content collections, and fullstack apps with server routes.
Read [instructions.md](./instructions.md) before an agent starts editing or deploying this template.

## Quick Start

```bash
bun install
bun run dev
```

Use `smallforce app init`, `smallforce app deploy`, and `smallforce app status`. The CLI keeps `smallforce.json` updated with app id, latest deployment id, requested capabilities, and deployment URL.
